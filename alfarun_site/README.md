# Альфаран — демо-прототип сайта

Файл `index.html` — статический одностраничный сайт. Видео пользователя сохранено как `assets/hero.mp4`.

## Что внутри
- Фоновое hero-видео с вашим MP4.
- Верхняя панель, которая появляется при прокрутке.
- Анимация загрузки с логотипом.
- Блок ключевых преимуществ.
- «Немного о компании» и «Наши надежные партнеры».
- 8 категорий спецтехники с интерактивными модальными карточками.
- Реальные характеристики LiuGong 856H, 922E, 764A, 385B, 4180D и 6626E на основе данных производителя.
- Ориентиры аренды в USD. Это рыночные ориентиры, не официальный прайс Альфаран.
- Раздел «Акции и предложения».
- Переключатель 3 YouTube-видео пользователя с реальными превью YouTube.
- Свайпаемые новости и кнопки-стрелки.
- «Наши клиенты и партнеры».
- Раздел запчастей.
- Контакты и адрес.
- Адаптив под мобильные устройства.

## Запуск
Откройте `index.html` в браузере. Для корректной работы некоторых внешних изображений и YouTube-превью нужен интернет.
